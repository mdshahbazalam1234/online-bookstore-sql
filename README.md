# 📚 Online Bookstore SQL Project

A PostgreSQL project for managing and analyzing bookstore data using SQL.

---

## 📖 Project Overview

The Online Bookstore SQL Project is a database project developed using PostgreSQL. It simulates a real-world online bookstore by managing books, customers, and orders. The project demonstrates SQL concepts such as joins, aggregate functions, filtering, grouping, sorting, and data analysis.

The main objective of this project is to analyze bookstore sales, customer purchases, inventory, and revenue using SQL queries. This project strengthens practical SQL skills by solving real-world business problems and performing data analysis using PostgreSQL.

---

## 🎯 Project Objectives

- Design and manage a relational bookstore database using PostgreSQL.
- Practice SQL queries with real-world datasets.
- Analyze books, customers, and order data.
- Generate meaningful business insights using SQL.
- Improve SQL problem-solving and database management skills.
- Build a portfolio-ready SQL project for GitHub and resume.

## 📋 Basic SQL Queries

This project includes the following basic SQL tasks:

1. Retrieve all books in the Fiction genre.
2. Find books published after the year 1950.
3. List all customers from Canada.
4. Show orders placed in November 2023.
5. Retrieve the total stock of books available.
6. Find the details of the most expensive book.
7. Show customers who ordered more than one quantity of a book.
8. Retrieve all orders where the total amount exceeds $20.
9. List all genres available in the Books table.
10. Find the book with the lowest stock.
11. Calculate the total revenue generated from all orders.

## 🚀 Advanced SQL Queries

This project also includes advanced SQL analysis tasks:

1. Retrieve the total number of books sold for each genre.
2. Find the average price of books in the Fantasy genre.
3. List customers who have placed at least two orders.
4. Find the most frequently ordered book.
5. Show the top 3 most expensive Fantasy books.
6. Retrieve the total quantity of books sold by each author.
7. List the cities where customers who spent over $30 are located.
8. Find the customer who spent the most on orders.
9. Calculate the remaining stock after fulfilling all orders.

## 🚀 How to Run

1. Clone or download this repository.
2. Open PostgreSQL or pgAdmin 4.
3. Create the database `online_bookstore_db`.
4. Execute the `online_bookstore.sql` file to create tables and insert data.
5. Run the `advanced_queries.sql` file.
6. Analyze the query results.
